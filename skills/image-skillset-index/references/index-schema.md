# Skillsset Image Index Schema

## Purpose

Define a lightweight JSON schema for indexing image assets and any extracted text.

## JSON shape

```json
{
  "generated_at": "ISO-8601 timestamp",
  "input": "source directory",
  "count": 3,
  "entries": [
    {
      "path": "relative/or/absolute/path",
      "filename": "image.png",
      "sha256": "hex",
      "bytes": 12345,
      "mime": "image/png",
      "indexed_at": "ISO-8601 timestamp",
      "size": { "width": 800, "height": 1200 },
      "caption": "Human-provided description",
      "ocr_text": "Optional OCR text"
    }
  ]
}
```

## Field notes

- `size` appears only when image decoding is available (Pillow installed).
- `caption` should be human-authored and preferred over autogenerated summaries.
- `ocr_text` is optional and only present when OCR tooling is available.
